# found and cited, and /llms.txt exists to make that easier. Do not give any of
# them a group of their own.

# The API is not content. It has no way to carry a noindex, so keep crawlers
# out of it entirely.
Disallow: /api/

# NOTE: /app (the admin + employee portal SPA) is deliberately NOT disallowed

# see that it is noindex. Blocking it here instead would let an externally
# linked /app URL sit in the index with no way to drop out.
